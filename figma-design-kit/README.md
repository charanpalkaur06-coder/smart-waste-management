# Figma design kit — Smart Waste Management

Blueprint for recreating the React app in Figma. **This folder does not create a file on figma.com** — you create the file manually using these specs.

## Contents

| File | Purpose |
|------|---------|
| [`design-tokens.json`](./design-tokens.json) | Machine-readable tokens (colors, type, spacing, radii, shadows) |
| [`DESIGN-TOKENS.md`](./DESIGN-TOKENS.md) | Human-readable token tables for Figma styles |
| [`SCREEN-INVENTORY.md`](./SCREEN-INVENTORY.md) | All screens, frame sizes, layout notes |
| [`COMPONENT-SPECS.md`](./COMPONENT-SPECS.md) | Sidebar, header, cards, table row, alerts, buttons, badges |
